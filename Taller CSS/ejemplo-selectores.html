Selectores CSS

Selector / Propiedad Función principal Ejemplo de uso
.clase Selecciona elementos con el atributo class específico
.destacado { color: red; }
Se aplica a: <div class="destacado">
#id Selecciona un elemento con el atributo id específico
#menu-principal { background-color: #333; }
ID debe ser único en la página
elemento Selecciona todos los elementos de ese tipo
p { line-height: 1.5; }
Afecta a todos los párrafos
selector1, selector2 Agrupa selectores para aplicar el mismo estilo
h1, h2, h3 { font-family: 'Arial', sans-serif; }
Aplica a todos los encabezados h1, h2 y h3
elemento:hover Se aplica cuando el usuario pasa el cursor sobre el elemento
button:hover { background-color: #4CAF50; transform: scale(1.05); }
Pseudo-clase para efectos interactivos

Texto y Tipografía

Propiedad Función principal Ejemplo de uso
color Define el color del texto
h1 { color: #2c3e50; } /* También con nombres o rgb() */ p { color: rgb(100, 100, 100); }
font-size Define el tamaño de la fuente
body { font-size: 16px; /* px, em, rem, % */ } h1 { font-size: 2.5rem; /* Relativo al root */ }
font-family Especifica la familia tipográfica
body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; }
Siempre incluir fuentes de respaldo (fallback)
text-align Alineación horizontal del texto
.centrado { text-align: center; } .derecha { text-align: right; } .justificado { text-align: justify; }
line-height Define el espacio entre líneas de texto
p { line-height: 1.6; /* Sin unidades = multiplicador */ } .espaciado { line-height: 2; /* Doble espacio */ }

Modelo de Caja (Box Model)

Propiedad Función principal Ejemplo de uso
width / height Define ancho y alto del elemento
.caja { width: 300px; height: 200px; } .porcentaje { width: 50%; /* Relativo al contenedor */ }
margin Espacio externo alrededor del elemento
div { margin: 20px; /* Todos los lados */ margin: 10px 20px; /* Arriba/abajo, izquierda/derecha */ margin: 10px 20px 15px 5px; /* Arriba, derecha, abajo, izquierda */ }
margin: auto; centra horizontalmente elementos en bloque
padding Espacio interno entre el contenido y el borde
.contenedor { padding: 15px; } .boton { padding: 10px 25px; /* Arriba/abajo, izquierda/derecha */ }
border Define el borde del elemento
img { border: 2px solid #3498db; border-radius: 8px; /* Bordes redondeados */ } .linea-superior { border-top: 1px dashed #ccc; }
box-sizing Controla cómo se calculan width y height
* { box-sizing: border-box; /* Incluye padding y border en width/height */ }
Recomendado para layouts más predecibles

Fondos y Bordes

Propiedad Función principal Ejemplo de uso
background-color Define el color de fondo
header { background-color: #2c3e50; } .transparente { background-color: rgba(0, 0, 0, 0.5); }
background-image Establece una imagen de fondo
.hero { background-image: url('imagen.jpg'); background-size: cover; /* Cubre todo el área */ background-position: center; }
border-radius Redondea las esquinas de un elemento
.redondo { border-radius: 10px; } .circulo { border-radius: 50%; /* Crea un círculo */ } .esquina-personalizada { border-radius: 15px 5px 20px 0; }
box-shadow Añade sombra a un elemento
.sombra { box-shadow: 2px 2px 10px rgba(0, 0, 0, 0.1); } .sombra-difuminada { box-shadow: 0 5px 15px rgba(0, 0, 0, 0.3); } /* Sintaxis: offset-x offset-y blur-radius color */

Posicionamiento

Propiedad Función principal Ejemplo de uso
position Define el método de posicionamiento
.relativo { position: relative; top: 10px; /* Desplaza 10px desde su posición normal */ } .fijo { position: fixed; top: 0; left: 0; /* Fijo en la esquina superior izquierda */ } .absoluto { position: absolute; bottom: 0; right: 0; }
display Define cómo se muestra un elemento
.en-linea { display: inline; /* Como un span */ } .en-bloque { display: block; /* Como un div */ } .oculto { display: none; /* Elimina del flujo del documento */ }
z-index Controla el orden de apilamiento
.superpuesto { position: relative; z-index: 10; /* Aparece por encima de elementos con z-index menor */ }
Solo funciona con elementos posicionados (position ≠ static)

Flexbox (Diseño Flexible)

Propiedad Función principal Ejemplo de uso
display: flex Convierte un contenedor en flexbox
.contenedor { display: flex; }
Los elementos hijos se convierten en elementos flex
justify-content Alineación horizontal de los elementos flex
.contenedor { justify-content: center; /* Centra horizontalmente */ justify-content: space-between; /* Espacio uniforme entre */ justify-content: space-around; /* Espacio alrededor */ }
align-items Alineación vertical de los elementos flex
.contenedor { align-items: center; /* Centra verticalmente */ align-items: stretch; /* Estira para llenar (por defecto) */ align-items: flex-start; /* Alinea al inicio */ }
flex-direction Dirección de los elementos flex (fila/columna)
.contenedor { flex-direction: row; /* Horizontal (por defecto) */ flex-direction: column; /* Vertical */ flex-direction: row-reverse; /* Horizontal invertido */ }

CSS Grid (Diseño en Cuadrícula)

Propiedad Función principal Ejemplo de uso
display: grid Convierte un contenedor en grid
.contenedor { display: grid; }
Los elementos hijos se convierten en elementos grid
grid-template-columns Define las columnas del grid
.contenedor { grid-template-columns: 1fr 1fr 1fr; /* 3 columnas iguales */ grid-template-columns: repeat(3, 1fr); /* Equivalente */ grid-template-columns: 200px 1fr 2fr; /* Combinación */ }
grid-template-rows Define las filas del grid
.contenedor { grid-template-rows: auto 100px; /* Primera fila automática, segunda 100px */ }
gap Espacio entre filas y columnas (grid-gap)
.contenedor { gap: 20px; /* Espacio entre filas y columnas */ row-gap: 10px; /* Solo entre filas */ column-gap: 30px; /* Solo entre columnas */ }
